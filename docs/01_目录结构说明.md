## 核心后端包说明

`novel_system/` 当前是项目主业务包，包含以下模块：

| 路径 | 当前用途 | 备注 |
|---|---|---|
| `api.py` | FastAPI 应用工厂、路由注册、静态资源挂载、Dashboard 模板渲染 | 入口为 `create_app()` 和模块级 `app` |
| `service.py` | `NovelSystemService` 门面和 `create_service()` 工厂 | 工厂当前返回 `GraphService()` |
| `services/` | 服务 Mixin 层，拆分 ask、continue、indexing、stats 和 base 初始化 | 当前服务由多重继承组合 |
| `config.py` | `.env` 和环境变量加载，路径与模型配置 | 全局配置依赖 |
| `models.py` | API、planner、trace、graph、eval、token 等 Pydantic 模型 | 单文件模型较集中 |
| `indexing.py` | 书籍 manifest、章节解析、artifact 构建、向量索引、场景和人物注册表 | 文件较大，边界不清 |
| `retrieval.py` | `HybridRetriever` 兼容层和 `RetrievalHit` 类型 | 真实检索委托给 `search/orchestrator.py` |
| `search/` | 检索编排、Profile、RRF、TF-IDF、dense search、GraphRAG | 当前检索主实现 |
| `validator.py` | EvidenceGate、AnswerValidator、ContinuationValidator、SpoilerGuard | 单文件职责较多 |
| `llm.py` | MiniMax、Mimo 和 fallback 路由 | 命名和实例化边界待优化 |
| `graph_service.py` | 交互图谱、canon、timeline 扩展服务 | 继承并覆盖 service 方法，边界不清 |
| `graph_name_policy.py` | 图谱名称规范化、别名和 Profile 策略 | 与 planner 别名扩展有重叠，待确认 |
| `embedding/` | EmbeddingProvider 抽象、CUDA/OpenVINO 实现 | 结构清晰 |
| `vector_store/` | 向量存储抽象和 FAISS 实现 | 结构清晰 |
| `reranker/` | Reranker 抽象、工厂和 rule_based 实现 | 结构清晰 |
| `entity_extractor.py` | 实体提取 | 与 indexing 中的人名提取是否重叠待确认 |
| `semantic_scorer.py` | 语义评分 | 被 EvidenceGate 使用 |
| `novel_heuristics.py` | 小说领域规则配置 | 不是普通工具，属于领域规则 |
| `tracing.py` | TraceLogger 和结构化 trace 日志 | 被 QA/续写链路调用 |
| `utils/` | 文本工具函数 | 当前主要服务 indexing |

详细入口、依赖和调用关系见 `docs/03_核心模块说明.md`。

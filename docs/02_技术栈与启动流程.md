# 02 技术栈与启动流程

> 生成日期：2026-05-23

## 1. 项目类型

**后端为主的全栈项目**。后端使用 Python + FastAPI，前端为服务端渲染的 Jinja2 模板 + 原生 JS，无独立前端构建流程。

### 2.5 路由方案

**后端路由**：FastAPI 路由，集中在 `novel_system/api.py` 的 `create_app()` 函数中定义。

路由清单：

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/` | Dashboard 页面（Jinja2 模板渲染） |
| GET | `/api/books` | 获取书籍列表 |
| POST | `/api/books` | 注册/导入书籍 |
| DELETE | `/api/books/{book_id}` | 删除书籍 |
| GET | `/api/books/{book_id}/status` | 获取书籍索引状态 |
| POST | `/api/books/{book_id}/index` | 索引书籍 |
| POST | `/api/books/{book_id}/start-index` | 启动异步索引 |
| GET | `/api/books/{book_id}/artifacts` | 获取产物目录 |
| GET | `/api/books/{book_id}/artifacts/{name}` | 获取具体产物 |
| GET | `/api/books/{book_id}/reader` | 阅读台数据 |
| POST | `/api/books/{book_id}/ask` | 证据问答 |
| POST | `/api/books/{book_id}/continue` | 受约束续写 |
| GET/PUT | `/api/books/{book_id}/canon` | 正典记忆管理 |
| GET | `/api/books/{book_id}/timeline` | 事件时间线 |
| GET | `/api/books/{book_id}/graph` | 人物关系图谱 |
| GET | `/api/storage-stats` | 存储统计 |
| GET | `/api/token-stats` | Token 使用统计 |
| GET | `/api/dashboard` | Dashboard 数据 |

**前端路由**：Hash-based 路由（待确认 `app.js` 中实现方式）。

### 2.6 状态管理方案

**后端状态**：
- `NovelSystemBase.__init__()` 中初始化各组件实例（LLM、Planner、Retriever、Validator 等）
- `session_memory: dict[str, list[ConversationTurn]]` — 按 session_id 管理会话历史
- `token_usage: dict[str, dict[str, int]]` — 按 book_id 管理 Token 用量
- `BookIndexRepository._cache` — 书籍索引内存缓存

**前端状态**：
- `static/app.js` 内部维护当前 book、graph、indexing status、UI mode 等状态
- 无框架状态管理（无 Redux、Vuex 等）

### 2.7 UI 组件方案

**无组件框架**。前端为原生 HTML/CSS/JS，所有 UI 逻辑在 `static/app.js` 中。

UI 区域划分（基于 `dashboard.html`）：
- Tab 导航：藏书 / 阅读台 / 知识图 / 续写台 / 评测
- 藏书视图：书籍卡片网格
- 阅读台：左侧章节目录 + 中间正文 + 右侧证据问答
- 知识图：Canvas 图谱 + 人物卡 + 时间线
- 续写台：指令输入 + 生成结果
- 评测：指标网格 + 基线对比 + 失败案例

### 2.8 数据请求方案

**后端外部调用**：
- `requests` 库直接调用 MiniMax / Mimo API（非 SDK）
- 全局限频器（`_throttle()`）避免触发 429
- 指数退避重试（最多 5 次，2/4/8/16/32 秒）

**前端数据请求**：
- `fetch()` API（待确认 `app.js` 中具体封装方式）

## 3. 启动流程

### 3.1 开发环境启动

```bash
# 1. 激活 conda 环境
conda activate chaishu

# 2. 安装依赖（首次）
pip install -r requirements.txt

# 3. 配置环境变量
cp .env.example .env
# 编辑 .env 填入 API key

# 4. 启动服务
python start_server.py
# 或
conda run -n chaishu python start_server.py
```

服务启动后访问 `http://localhost:8000`。

### 3.2 启动流程详解

```
start_server.py
  └─ from novel_system.api import app
     └─ app = create_app()
        ├─ config = AppConfig.load()
        │   └─ _load_dotenv(ROOT_DIR / ".env")
        │   └─ 从环境变量加载所有配置
        ├─ service = create_service()
        │   └─ return GraphService()
        │      └─ GraphService.__init__() → NovelSystemService.__init__() → NovelSystemBase.__init__()
        │         ├─ embedding_provider = create_embedding_provider(config)
        │         ├─ repo = BookIndexRepository(config, embedding_provider)
        │         ├─ llm = MiniMaxClient(config)  # MiniMax + Mimo 路由器
        │         ├─ planner = RuleBasedPlanner()
        │         ├─ query_rewriter = QueryRewriter()
        │         ├─ semantic_scorer = SemanticScorer(...)
        │         ├─ evidence_gate = EvidenceGate(...)
        │         ├─ answer_validator = AnswerValidator()
        │         ├─ continuation_validator = ContinuationValidator()
        │         ├─ spoiler_guard = SpoilerGuard()
        │         ├─ reranker = create_reranker(config)
        │         └─ bootstrap_default_book()  # 确保默认书籍 manifest 存在
        ├─ app = FastAPI(title="Novel System Workspace")
        ├─ app.add_middleware(CORSMiddleware, ...)
        ├─ app.mount("/static", ...)
        └─ 注册所有路由 (@app.get/post/put/delete)
  └─ uvicorn.run(app, host="0.0.0.0", port=8000)
```

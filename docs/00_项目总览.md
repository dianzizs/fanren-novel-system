## 项目定位

**小王一号**是一个**长篇小说智能工作台**（Long-form Fiction Workspace），面向小说拆书、问答、续写和知识图谱分析场景。

核心能力：
- 导入小说文本，自动解析章节、构建索引
- 基于证据的问答（Evidence-based QA）
- 受约束续写（Continuation with spoiler guard）
- 人物关系图谱与事件时间线可视化
- 检索评测与 trace 追踪

## 一句话架构

```
Dashboard (HTML/JS) → FastAPI → NovelSystemService → Planner / Retrieval / Validator / LLM / Graph / IndexRepository
```

## 项目类型

- **后端为主**的全栈项目
- 后端：Python + FastAPI
- 前端：服务端渲染 Jinja2 模板 + 原生 JS（无框架）
- 无独立前端构建流程

## 关键风险提示

1. **Embedding Server 稳定性**：如果本地 OpenVINO/CUDA Server 挂掉，索引和查询都会失效。
2. **GraphRAG API 不稳定性**：GraphRAG Python API 仍处于活跃开发中，版本升级可能带来 Breaking Changes。
3. **长篇小说长尾实体**：对于极其长的小说（如 2000 章以上），社区报告生成的计算量可能呈指数增长。

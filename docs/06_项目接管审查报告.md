## 一、项目真实结构判断

### 1. 当前项目最核心的主流程

当前项目真实主流程不是单纯的“检索问答脚本”，而是一个以 FastAPI Dashboard 为入口的小说工作台：

```text
templates/dashboard.html + static/app.js
  -> novel_system/api.py:create_app()
  -> novel_system/service.py:create_service()
  -> novel_system/graph_service.py:GraphService
  -> services/base.py 初始化 repo / llm / planner / retriever / validator / reranker
  -> services/qa.py:ask() 或 services/continuation.py:continue_story()
  -> indexing.py / retrieval.py -> search/orchestrator.py / validator.py / llm.py
```

依据：
- `docs/00_项目总览.md` 已给出 `Dashboard -> FastAPI -> NovelSystemService -> Planner / Retrieval / Validator / LLM / Graph / IndexRepository`。
- `novel_system/api.py` 中 `create_app()` 注册 `/`、`/api/books`、`/api/books/{book_id}/ask`、`/continue`、`/graph` 等端点。
- `novel_system/service.py:create_service()` 当前实际返回 `GraphService()`，而不是纯 `NovelSystemService`。
- `novel_system/services/qa.py` 当前仍 `from ..retrieval import HybridRetriever, RetrievalHit`，说明运行主线还没有完全绕过 `retrieval.py`。
